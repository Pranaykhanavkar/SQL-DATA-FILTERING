# SQL-DATA-FILTERING
A practical SQL project focused on data retrieval, filtering, and sorting using MySQL. This project demonstrates how to extract specific records from datasets using SQL conditions and filtering operators.

Key Concepts:

SELECT and WHERE
AND and OR operators
BETWEEN
IN
LIKE
ORDER BY
Filtering and sorting records
Tool Used: MySQL Workbench

Objective: To strengthen SQL querying skills and learn how to retrieve relevant information efficiently from databases.
